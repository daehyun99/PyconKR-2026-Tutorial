### Detailed Explanation of the Tutorial

This tutorial is designed for beginners in causal analysis. By the end of the session, participants will understand the core concepts of causal analysis and be able to perform basic causal discovery, parameter learning, and causal inference using the open-source library [`pgmpy`](https://github.com/pgmpy/pgmpy).

1. Understand the differences between correlation and causation, and between prediction and inference, using synthetic data.
2. Learn the basic structures and key properties of causal graphs.
3. Learn causal discovery, which identifies the structure of a causal graph from data.
4. Learn parameter learning, which estimates the probability distributions associated with a causal graph.
5. Learn probabilistic inference and causal inference using a learned causal model.
6. Explore ongoing research and development in `pgmpy` related to the parameterization of causal models.
